Lektion 0: Für wen ist KaraLib?

KaraLib ist eine Python-Bibilothek. Das heißt, dass sie auf der Programmiersprache Python aufgebaut ist.

Wenn du diese Programmiersprache lernen möchtest, bist du hier richtig.
