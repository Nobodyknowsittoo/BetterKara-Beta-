0. Ideen, was eine IDE ist?

#Theorie

IDE steht für integrated development environment.

integrated (integriert) development (Entwicklung) environment (Umbgebung)

Das bedeutet, es ist ein Programm mit dem du etwas entwickeln kannst.

Was entwickeln? Das kannst du dir selbst aussuchen. Dazu musst du allerdings erst programmieren lernen. Wenn du das noch nicht gemacht hast, kannst du hier starten.

Die Entwicklungsumgebung müssen wir allerdings erst einrichten.

1. Visual Studio Code

In dieser Anleitung verwenden wir Visual Studio Code. Es ist eine ziemlich einfache Entwicklungsumgebung. Du kannst aber auch jede andere IDE verwenden.

Lade hier VSCode für dein Betriebssystem herunter: Offizielle Website von VSCode

Dann kannst du einfach die heruntergeladene Datei öffnen und den Installationsprozess durchlaufen.
